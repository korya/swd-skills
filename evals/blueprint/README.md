# blueprint evals

Measures whether `/blueprint` produces a plan a human can accept or reject from its first
two sections, grounded in the repo's own docs. The fixture is ticketdesk with agent docs
generated by `/repo-docs`, so the plan has specs, invariants, and conventions to cite.

## Layout

- `make_fixture.sh <dir>` builds a git repo at `<dir>` with one commit.
- `fixture/` is the project tree, code plus `AGENTS.md` and `docs/`.
- `evals.json` holds one eval in the skill-creator benchmark format.
- `check_run.py <run-dir>` grades the mechanical assertions.

## Traps in the fixture

| Trap | Tests |
|---|---|
| `unittest` and `make`, no pytest, no poetry | conventions read from the repo, not from training data |
| INV-001 and INV-002, append-only log | overdue is derived at read time, not written as an event |
| `Ticket.due_at` already computed | reuse, not reinvention |
| `EventStore.clock` is injectable | the clock source for "now" is named and validated |
| CLI-001 lists the commands | a new subcommand means a spec update, flagged |

## Running

Run with the skill-creator benchmark flow, old skill against new skill. Grade the prose
assertions with `scripts/prose-lint.py`.
